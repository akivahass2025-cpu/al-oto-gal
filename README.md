# 🌊 על אותו גל

משחק לזוגות וחברים: כמה אתם באמת חושבים אותו דבר?
22 חפיסות, 1,320 שאלות, מצב התאמה ומצב ניחוש, הישגים ודרגות.

## להתקנה בטלפון (אנדרואיד)
נכנסים ל-**Releases** במאגר, מורידים את `al-oto-gal.apk` ופותחים אותו.
כל גרסה חדשה מותקנת על הקודמת, וההתקדמות נשמרת.

## אונליין
"משחק חדש" ← "כל אחד מהטלפון שלו" פותח חדר עם קוד של 4 ספרות.
החבר/ה לוחצ/ת "הצטרפות לחדר" ומקליד/ה את הקוד.
החדרים נשמרים במסד הנתונים של Firebase של "זה או זה" (תחת rooms/gal…).

## מבנה
- `src/game.html` – המשחק (עיצוב ולוגיקה)
- `src/decks/*.json` – החפיסות והשאלות
- `node tools/build.js` – בונה את `index.html` מכל החלקים
- `android/` – עטיפת האפליקציה, נבנית אוטומטית ב-GitHub Actions בכל דחיפה
- `tools/e2e/online.mjs` – בדיקה אוטומטית: שני טלפונים משחקים משחק אונליין מלא (רצה ב-Actions)
